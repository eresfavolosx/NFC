## 2024-05-14 - Custom Toggle Switch Accessibility
**Learning:** In custom toggle switch implementations using `<label>` and `<input type="checkbox">` elements, the checkbox often lacks an explicit accessible name when the visual text label is placed adjacent to the `<label>` wrapper rather than inside it, or when it relies on implicit association without proper attributes. This pattern is prevalent in `settings.js` and `writer.js`.
**Action:** When creating or modifying custom toggle switches, always explicitly link the descriptive text to the checkbox input using the `for` attribute on the `<label>` element and the `id` attribute on the input. Additionally, link any supplementary helper text using the `aria-describedby` attribute on the input to ensure complete context is provided to screen readers and to maximize the clickable target area.
